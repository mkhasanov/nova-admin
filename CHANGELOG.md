# Changelog

All notable changes to NovaAdmin are documented here.

## [1.0.0] - 2026-10-06

### Added
- Premium dark and light admin dashboard experience
- Responsive sidebar, topbar, and mobile drawer layout
- Dashboard, users, products, orders, customers, analytics, reports, notifications, settings, profile, login, and 404 screens
- Local storage persistence for users, products, orders, notifications, login state, theme, and settings
- Chart.js visualizations and CSV export behavior
- Demo authentication with reset-ready mock data
- Documentation and customization guides

### Changed
- Initial release of the commercial-style dashboard template

### Fixed
- Focus states, table responsiveness, and mobile navigation behaviors
- Theme persistence and default demo data reset flow
